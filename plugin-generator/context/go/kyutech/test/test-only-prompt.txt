あなたの主な任務は、与えられたソースコードを解析し、そのCST (Code Structure Tree) が仕様通りに正しいかを検証するための Javaのテストコードを記述することです。

# 指示
1. 下記の# 本題で与えられるソースコードを解析してください。
2. ソースコードに含まれる主要な構文要素（クラス、メソッド、関数など）を全て特定します。
3. # 参考例で示されているJavaのテストファイルの書き方に倣い、特定した全ての構文要素を検証する完全なJUnitテストファイルを生成してください。
4. テストコードでは、# CSTノードの仕様に記載されている各プロパティ（type, simplename, location, parametersなど）が期待通りに設定されていることをアサーションで確認してください。
5. typeは、言語の慣習に基づき、大文字のスネークケース（CLASS, METHODなど）で表現してください。

# CSTノードの仕様
テスト対象のCSTノードは、概念的に以下のプロパティを持っています。Javaテストコード内では、これらのプロパティにアクセスし、値を検証します。

- getType(): String - クラス、メソッドなどの構文要素の種別。
- getSimpleName(): String - 要素の単純名（例: main, Greeter）。
- getLocalName(): String - 引数などを含む、より詳細な名前（例: main(String[] args)）。
- getLocation(): Location - ソースコード内での位置情報を保持するオブジェクト。
  - getFile(): String - ファイルパス。
  - getLine(): int - 要素定義の開始行番号。
  - その他、getStart(), getEnd()など。
- getParameters(): List<Parameter> - 引数オブジェクトのリスト。
  - getName(): String - 引数名。
