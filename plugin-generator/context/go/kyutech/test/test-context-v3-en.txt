# Role
You are an expert at generating high-quality JUnit tests for a multi-language parser (UniversalPlugin) implemented in Java.
Your mission is to learn test implementation patterns from multiple languages and apply that knowledge to generate test cases for a new language.

# Context (Training Data)
To generate parser tests for the Go language, first, learn the language-independent common testing patterns from the following JavaScript and Ruby test implementations.

- Training Data 1: JavaScript
    - Overview:
        - Test Target (function.js): Code that covers various JavaScript function definitions (e.g., standard functions, arrow functions, anonymous functions).
        - Test Implementation (TestParser.java): A JUnit test that parses the aforementioned JS file and verifies that function names, line numbers, argument lists, etc., are correctly extracted as CST nodes.
    - File References:
        - Test Target Code
            - @refdiff-universal/src/test/resources/js/syntax/class/dir/class.js
            - @refdiff-universal/src/test/resources/js/syntax/file/dir/file.js
            - @refdiff-universal/src/test/resources/js/syntax/function/function.js
        - Test Implementation: @refdiff-universal/src/test/java/refdiff/parsers/universal/js/TestParser.java

- Training Data 2: Ruby
    - Overview:
        - Test Target (method.rb): Code containing multiple instance methods and class methods defined within a Ruby class.
        - Test Implementation (TestParser.java): A JUnit test that parses the aforementioned Ruby file and confirms that each method is correctly recognized as a CST node, along with its type (instance/class) and name.
    - File References:
        - Test Target Code: @refdiff-universal/src/test/resources/ruby/parse/method.rb
        - Test Implementation: @refdiff-universal/src/test/java/refdiff/parsers/universal/ruby/TestParser.java

# Task (Generation Target)
Apply the test patterns you learned above to generate a new Java JUnit test method that analyzes the following new Go test target file.

Generation Target: Go
- Overview:
    - Test Target (keyvalue.go): Go language code containing structs and functions. Specifically, it includes struct fields, methods, function definitions, and parameters.
    - Test Implementation (TestParser.java): A JUnit test that parses the aforementioned Go file and verifies that structs, fields, methods, and function definitions are correctly recognized as CST nodes.
- File Reference:
    - Test Target Code: 
        - @refdiff-universal/src/test/resources/go/syntax/keyvalue.go
        - @refdiff-universal/src/test/resources/go/syntax/runner.go
        - @refdiff-universal/src/test/resources/go/syntax/updater_windows.go
    - Test Implementation: @refdiff-universal/src/test/java/refdiff/parsers/universal/go/TestParser.java

# Output Requirements
- Generation Language: The output test code must be Java.
- Inference and Application:
- Infer the language's node types and use them, such as NodeTypes.FUNCTION and NodeTypes.STRUCT.
- Accurately map the code structure (packages, functions, type definitions, etc.) to ExpectedNode records.
- Naming Convention: The method name should clearly describe the feature of the language being tested, for example, shouldParseGoFunctionsAndStructsCorrectly.
- Structure Replication: Strictly reproduce the structure of the learned tests (use of SourceFolder, collection of CstNodes, creation of an ExpectedNode list, and the verification loop using assertThat).
- Format: Output the generated code as a complete Java method, suitable for being placed in a new refdiff/parsers/universal/go/TestParser.java file.
