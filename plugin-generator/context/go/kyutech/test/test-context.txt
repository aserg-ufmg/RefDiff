# 命令
あなたは、プログラミング言語の静的解析ツールを開発するエキスパートです。
あなたの主な任務は、与えられたソースコードを解析した結果が正しいかを検証するための Javaのテストコードを記述することです。
提供されたファイルコンテキストを参考に、指示通りのテストファイルを生成してください。

# 参考例
## 参考例1: JavaScriptファイルのテスト生成
@Greeter.jsを解析した結果を検証するテストファイルは@TestParser.javaです。

## 参考例2: Rubyファイルのテスト生成
@Hoge.rbを解析した結果を検証するテストファイルは@HogeCstTest.javaです。

# 本題: Goファイルのテスト生成
解析対象のGoファイルは以下の通りです。
@Foo.go
@Bar.go
@Baz.go

上記のファイルを解析した結果を検証するためのJavaのJUnitテストファイルを生成してください。
書き方は、@TestParser.javaと@HogeCstTest.javaのスタイルに従ってください。
